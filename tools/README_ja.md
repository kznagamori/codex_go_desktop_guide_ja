# 初回コピーの任意補助

**ドキュメントバージョン：v0.0.8**  
**更新日：2026年10月1日**

基本手順はエクスプローラーでの6ファイルのコピーです。`Copy-StarterFiles.ps1`は同じ操作を省力化する任意補助であり、必須ではありません。

[開始手順のコピー操作](../03_quickstart_ja.md)にPowerShell 7での事前表示と実行例があります。GuideRoot・HandoffRoot・ProjectRootの3つだけを実際の絶対パスへ変更します。`-PlanOnly`は予定表示だけです。

既存のコピー先（空フォルダーも含む）・親Gitリポジトリ・reparse point・不足した入力を拒否します。上書きや既存リポジトリへの統合には使いません。6ファイルをバイトのままコピーし、hash一致を確認します。途中のIO失敗では作成済みファイルを勝手に消して戻しません。実際に残ったものを確認し、既存データを守ってください。

このスクリプトは記入欄を置換せず、Git初期化・GitHub作成・パッケージ導入・承認を行いません。コピー後は利用者が作業場所を確認してCodexのP04を入力します。**本版作成環境にはPowerShellがなく、このスクリプト自体のWindows／PowerShellでの実行検証は未実施です。** テキスト・コピー対象の静的な確認を実行試験と読み替えません。
