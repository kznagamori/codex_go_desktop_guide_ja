# v0.0.9の文書監査記録

**ドキュメントバージョン：v0.0.9**  
**更新日：2026年10月2日**

## 1. 監査対象

全Markdown、C0・P01〜P40、両ハンズオン、開始手順、成果物テンプレートを対象に、P34の人による事前確認の入力方法と版の整合を点検した。参考実装、依存、CI設定、アプリ機能は変更対象外とした。

## 2. 変更の分類

| 対象 | 確認・変更内容 |
|---|---|
| 基礎ハンズオン | H05.1へ、文字数カウンター候補の対象版・候補ID・表示名・リポジトリ名・GitHub確認方法・日時・結果・未確認範囲の記入例を追加。 |
| 発展ハンズオン | D05.1へ、Markdownビューア候補について同じ粒度の記入例を追加。 |
| 未実施の扱い | 人が事前確認していない場合は`未実施`と記入し、Codexが確認できないログイン・権限項目を未確認で残す例を追加。 |
| 誤認防止 | 検索未検出や作成画面の警告なしを、使用可能・取得可能・予約済み・権利確認済みと扱わない表現へ統一。 |
| 版管理 | 配布資料一式をv0.0.9、更新日を2026年10月2日へ更新。過去版の本文・履歴は過去の記録として保持。 |

## 3. 検査範囲と限界

`validation/check_guide.py`で版ヘッダー、リンク、アンカー、コードフェンス、共通／単独／統合入力、章順、P38の一致、P34記入例、参考実装の基準hashを確認する。検査結果は`validation/document-check.json`と`validation/prompt-check.json`へ記録する。

例示したGitHub画面・候補名について実際の可用性、権利、予約、公開可否を調査したものではない。モデルへ全入力を送る通し試験、利用者の実リポジトリ、GUI、PowerShell、GitHub Actions、公開操作も実施していない。
