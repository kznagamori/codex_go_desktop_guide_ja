# v0.0.8の文書監査記録

**ドキュメントバージョン：v0.0.8**  
**更新日：2026年10月1日**

## 1. 監査対象

全Markdown、C0・P01〜P40の共通／単独／統合入力、両ハンズオン、開始手順、成果物テンプレートを対象に、文書状態の遷移と後工程の開始条件を点検した。参考実装、依存、CI設定、アプリの機能は変更対象外とした。

## 2. 変更の分類

| 対象 | 確認・変更内容 |
|---|---|
| 全体ワークフロー | 後工程で根拠または実行対象にする現在版は、P08（名称はP35）で全文承認しAPPROVEDにすることを基本経路として明記。 |
| REVIEWの例外 | 作業案同士の相互照合、版・節・IDを特定した部分承認、阻害事項から独立した調査・文書案、実績・索引だけの追記に限定。実装・外部操作へ広げない停止条件を追加。 |
| P08／P35 | 未決・未実施・未確認を正しく記載した文書は、その記載と停止条件を含めて全文承認できることを追加。事実の解決・実施・試験PASS・公開許可とは分離。 |
| 基礎／発展ハンズオン | 各計画・仕様をAPPROVEDにしながら進む規則を冒頭へ追加。H05／D05のP35を全文承認入力とし、APPROVEDを確認できなければ転記へ進まない。 |
| 開始手順 | naming.mdとidea.mdを全文承認してAPPROVEDにしてから後工程へ進む標準経路へ統一。 |
| 版管理 | 配布資料一式をv0.0.8へ更新。過去版の履歴・検査記録は過去の記録として保持。 |

## 3. 検査範囲と限界

`validation/check_guide.py`で版ヘッダー、リンク、アンカー、コードフェンス、共通／単独／統合入力、章順、P38の一致、参考実装の基準hashを確認する。検査結果は`validation/document-check.json`と`validation/prompt-check.json`へ記録する。

モデルへ全入力を送る通し試験、利用者の実リポジトリでの承認操作、GUI、PowerShell、GitHub Actions、公開操作は実施していない。静的検査のPASSは、それらの実行結果を保証しない。
