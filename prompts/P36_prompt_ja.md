# P36：名前の実物照合と最小の反映計画を作る

**ドキュメントバージョン：v0.0.7**  
**更新日：2026年10月1日**

**入力先：Codex CLI。** 各{...}を実値にして、下のブロックだけを送信します。元の共通集を別に送る必要はありません。

**送信前にユーザーが記入：** `{実在する作業パス}`、`{docs/ideas/naming.md等の実在パスと版／未作成}`、`{存在する場合の実在パス／未生成／対象外}`、`{新規への反映計画／取り込み後の照合／既存名称の現状維持／承認済み改名の影響調査}`、`{CR-ID／改名しない}`、`{命名記録の反映欄または指定する文書パス}`

実行条件・省略条件は[共通集のP36](../04_prompt_templates_ja.md#p36)を確認してください。人の承認が必要な入力は、対象版の内容を実際に確認した後だけ送信します。

````markdown
# P36：名前の実物照合と最小の反映計画を作る

## 入力・許可範囲

- 対象リポジトリ：{実在する作業パス}
- 名称の正本：{docs/ideas/naming.md等の実在パスと版／未作成}
- 雛形：{存在する場合の実在パス／未生成／対象外}
- 今回の扱い：{新規への反映計画／取り込み後の照合／既存名称の現状維持／承認済み改名の影響調査}
- 改名の変更要求：{CR-ID／改名しない}
- 結果の保存先：{命名記録の反映欄または指定する文書パス}
- 今回は読み取り調査と指定文書の記録・計画だけです。コード・設定・remote・GitHubは変更しません。

## 確認と記録

- 適用指示、Gitルート・HEAD・既存差分を確認し、利用者の変更を保持します。stateやrepo-mapは存在するものだけ読んでください。
- module、自プロジェクトのimport、bindings、GUI表示名、実行名、About、ビルド定義、CI成果物名、アーカイブ、README、必要なアプリID・保存先を照合します。
- 正式値・現物値・根拠パス・差分・必要な検証を表にします。未生成を読んだことにせず、未確認やN/Aには理由を付けます。
- 名前の文書がなければ、現物からnaming.mdのREVIEW案を作ります。既存使用の事実を記録しますが、人の承認を捏造しません。
- 実証の追記だけなら承認済みの名称表と版を維持します。名前の定義変更が必要なら別版のREVIEW案とし、過去承認を流用しません。

## 次の変更と保護

- 変更が必要な場合は最小のタスク案だけ作り、人のP08の後にP12で実行します。
- 変更不要ならその結果を記録します。生成前の計画だけを反映済みにしません。
- 第三者module・ライセンス・公開済み成果物・過去の試験記録は一括置換しません。
- 既存名の変更はP22の変更要求と承認を必要とし、表示名変更だけでmoduleや保存先を変えません。

## 終了条件

- 保存した記録を再読込みし、差分・未確認・必要な承認・次の1操作を示して停止してください。
- 書込みできない場合は未保存と報告し、本文案を出すだけにします。
- GUIを操作していない項目は、GUI確認済みとしません。
````
