# P35：確認した正式な名前の対応表を承認する

**ドキュメントバージョン：v0.0.9**  
**更新日：2026年10月2日**

**入力先：Codex CLI。** 各{...}を実値にして、下のブロックだけを送信します。元の共通集を別に送る必要はありません。

**送信前にユーザーが記入：** `{naming.mdの対象版}`、`{候補IDと表示名・リポジトリ名／決定済みの名前を維持}`、`{対象版の節番号・範囲}`、`{自分の名前または識別名}`、`{ローカル開発の名称使用など、具体的な範囲}`、`{ID・作成前／公開前など止める工程／なし}`

実行条件・省略条件は[共通集のP35](../04_prompt_templates_ja.md#p35)を確認してください。人の承認が必要な入力は、対象版の内容を実際に確認した後だけ送信します。

````markdown
# P35：確認した正式な名前の対応表を承認する

## 人による承認

- 確認した命名記録：docs/ideas/naming.md（対象版：{naming.mdの対象版}）
- 選ぶ名前：{候補IDと表示名・リポジトリ名／決定済みの名前を維持}
- 承認する対応表：{対象版の節番号・範囲}
- 承認者：{自分の名前または識別名}
- 使用を承認する範囲：{ローカル開発の名称使用など、具体的な範囲}
- 承認しない項目・残す未確認：{ID・作成前／公開前など止める工程／なし}
- 私が上記の正式表記と確認結果を実際に読み、この範囲を承認します。

## 記録と保存方法

- 保存方法：Codex CLIでdocs/ideas/naming.mdを編集・保存
- ローカルの対象ファイルを読み、対象版と選択した名前・表が一致するか確認してください。ChatGPTの出力を直接編集する依頼ではありません。
- 承認対象の表示名・GitHub所有者・リポジトリ名が本文の表に実値で存在することを確認します。未決・記入欄のまま・不整合、承認範囲を阻害する問題があれば状態を変えず停止します。P35で未決値を作ったり採用候補を切り替えたりしません。
- アプリID等の後工程で決める項目は、今回の承認範囲から明示的に除外され、必要になる工程で停止する記録があれば、名前3項目の範囲承認を妨げません。未実施の公開確認も解決済みにせず、ローカルでの使用承認と分けます。
- 全文の承認なら文書状態をAPPROVEDへ、一部の承認なら文書状態はREVIEWのまま承認範囲を履歴に記載します。
- 通常は、未確認事項と停止条件を含む現在版の記載全体を人が確認し、その記載を含む全文を承認してAPPROVEDにします。未確認事項を解決済み、GitHubを作成済み、公開許可済みとする意味ではありません。一部承認でREVIEWを維持する場合は、承認済みの版・節・キーと除外範囲、進めてよい次工程、停止する工程を履歴へ明記してください。
- 名前の表・方針・未決事項など承認対象の本文と対象版は変えず、承認者・実際の日時・対象版と範囲・この発言を根拠とする承認履歴を追加します。日時を確認できなければ捏造せず確認待ちにします。
- 名称決定、GitHub作成状況、公開判断を別に記録し、未実施の調査を済ませたことにしません。
- idea.mdへ反映するアプリ表示名・GitHub所有者・GitHubリポジトリ名・完全名・URLと作成状況・正本参照・同期元版は、P38で転記するための差分案だけ示してください。リンクだけの案にしません。idea.mdの変更・承認は今回は行いません。
- Codexで実際に保存し、再読込みした管理欄・承認履歴と差分を示します。git statusと本文でも確認し、書込み不可なら未保存と報告します。「了解しました」だけで保存完了としません。

## 許可しないことと終了条件

- GitHub作成・改名・公開・remote変更、commit/push/tag/Releaseを許可していません。
- module・コード・CI・依存・設定保存先・アプリIDの変更も許可していません。
- 決定記録、残る未確認、idea.mdの反映案、次の1操作（未反映ならP38）を示して停止してください。
````
